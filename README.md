# MiniGPT

A lightweight implementation of a Generative Pre-trained Transformer (GPT) model from scratch.

## Overview

MiniGPT is designed for educational exploration, experimentation, and understanding the core mechanics of transformer-based language models:
- Multi-head self-attention mechanisms
- Transformer decoder blocks
- Token & positional embeddings
- Training, loss calculation, and autoregressive text generation

## Getting Started

### Prerequisites

- Python 3.8+
- PyTorch

### Setup

```bash
git clone https://github.com/sahil-mangla/MiniGPT.git
cd MiniGPT
```
